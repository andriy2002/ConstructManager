# ConstructManager

## Анотація

Будівництво та реконструкція зазвичай перевищують початково запланований термін. Багато затримок спричинені відсутністю організації з боку виконавців проекту, чого можна було б уникнути, якби управління було більш ефективним. Цей проект проводить дослідження інформаційних систем для управління будівництвом та розробляє мобільний додаток, який допомагає контролювати етапи будівництва та реконструкції. Метою цієї роботи є надання безкоштовного мобільного додатка, який допомагає інженерам та геодезистам керувати будівництвом та запобігати можливим затримкам у своїх проектах.
